# fixture_integration

Throwaway project used by the integration routine. It consumes `setup-spyder`
as an **external dependency** (downloaded from GitHub), exactly like another
repository would — nothing here imports this repo's `src/`.

From the repository root:

```shell
uv run setup-spyder-integration               # install from GitHub and open Spyder
uv run setup-spyder-integration --no-launch   # only install and check the import (CI)
uv run setup-spyder-integration --local       # install the working tree instead of GitHub
uv run setup-spyder-integration --ref develop # install from another branch/tag
uv run setup-spyder-integration --fresh       # recreate the project from scratch
uv run setup-spyder-integration --keep        # do not delete anything at the end
```

The `pyproject.toml`, `uv.lock`, `main.py`, `.venv/` and `.spyproject/` here are
generated by the routine and deleted when it finishes (unless you pass
`--keep`). They stay out of git either way; only this `README.md` is versioned.
